# Finance Manager

A Python-based personal finance management application for tracking income, expenses, and spending.

## Features

- Add income and expenses
- View all transactions
- Search transactions
- Delete transactions
- Calculate total income, expenses, and balance
- View spending by category
- Input validation
- Automatic transaction IDs
- Transaction dates

## Technologies

- Python
- Git & GitHub

## Current Status

Version 1 is currently implemented.

Future versions will add persistent data storage and other improvements.
