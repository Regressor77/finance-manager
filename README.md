# Finance Manager

A Python-based personal finance management application for tracking income, expenses, and spending.

## Features

- Add income and expenses
- View all transactions
- Search transactions
- Delete transactions
- Calculate total income, expenses, and balance
- View spending by category
- Input validation
- Automatic transaction IDs
- Transaction dates
- Persistent JSON data storage
- Modular code structure

## Technologies

- Python
- JSON
- Git & GitHub
